# KanbanFlow

Нативная канбан-доска для macOS, написанная на **Swift + AppKit + WKWebView + SQLite**.
Интерфейс — один самодостаточный HTML-файл, а нативная оболочка даёт окно,
базу данных, файловые диалоги и интеграцию с macOS.

**English version:** [README.md](README.md) · **Инструкция по сборке:** [BUILD.ru.md](BUILD.ru.md)

---

## Архитектура

Это гибридное macOS-приложение.

- **`kanban.html` — интерфейс.** Доска, модальные окна, темы и вся логика
  взаимодействия написаны на HTML, CSS и JavaScript и отображаются
  через `WKWebView`. 
- **`macos/main.swift` — нативная оболочка.** AppKit создаёт окно и строку меню,
  `WKWebView` показывает HTML, а нативный код отвечает за SQLite, файловые
  диалоги JSON, резервные копии и заголовок окна.

JavaScript и SQLite общаются через небольшой мост `WKScriptMessageHandler`
(`window.webkit.messageHandlers.kanbanDB`). При каждом сохранении интерфейс
передаёт полное состояние в JSON; нативный слой записывает его в `app_state`
и перестраивает нормализованные таблицы. Если открыть тот же `kanban.html`
в браузере, моста нет и страница использует `localStorage`.

## Возможности

- **Отмена действий** — кнопка **Undo** в шапке или `Cmd+Z` отменяет последнее
  изменение. История хранится в памяти и содержит до 50 шагов за сеанс.
- **Несколько досок** с выпадающим переключателем, созданием и удалением досок.
- **Колонки и карточки** с перетаскиванием между колонками, цветными разделителями
  с подписями, метками, приоритетами, исполнителями, описаниями и подзадачами.
- **Управление колонками** — кнопка копирования в заголовке колонки дублирует её
  вместе с карточками; перетаскивание заголовка меняет порядок колонок. Порядок
  сохраняется в базе данных.
- **Кнопка «Готово»** — на каждой карточке есть галочка. При первом нажатии
  выбираются одна или несколько колонок завершения (например, «Готово»), затем
  куда переместить карточку. При следующих нажатиях предлагаются только
  выбранные ранее колонки. Выбор можно изменить в настройках. Завершённые
  карточки отмечены зелёной галочкой на доске, в проектах и в календаре.
- **Щелчок по дню в календаре** создаёт новую задачу с уже заполненной датой.
- **Диапазоны дат** — дата начала и необязательная дата окончания. Просрочка
  определяется по дате окончания; календарь показывает все дни диапазона, а при
  перетаскивании карточки длительность сохраняется.
- **Три режима** — доска, календарь и плитки проектов.
- **Поиск и фильтры** по метке, приоритету и исполнителю.
- **Четыре темы** — тёмная, светлая, синяя и зелёная.
- **Переименование приложения** в настройках. Имя отображается в шапке, заголовке
  окна macOS и в экспортируемых резервных копиях.
- **Настоящая база данных** SQLite: авторитетный JSON-снимок плюс нормализованные
  таблицы досок, колонок, карточек, разделителей и настроек.
- **Резервные копии и перенос данных** — полный JSON-бэкап и восстановление через
  нативные диалоги macOS, а также экспорт/импорт отдельной доски.
- **Работа в браузере** — если открыть `kanban.html` напрямую, приложение
  использует `localStorage` и не требует нативной оболочки.

## Требования

- macOS 12 Monterey или новее.
- Xcode Command Line Tools (компилятор Swift и macOS SDK):

  ```bash
  xcode-select --install
  swiftc --version
  ```

Electron, Node.js, менеджеры пакетов и сторонние среды выполнения не нужны.

## Быстрый старт

```bash
git clone https://github.com/ilyaivonin/kanbanflow
cd kanbanflow
./macos/build.sh
open dist/KanbanFlow.app
```

Сборка создаёт `dist/KanbanFlow.app`. Приложение можно перенести
в `/Applications`, чтобы оно появилось в Launchpad.

Подробности о сборке, подписи, иконке и устранении неполадок — в
[BUILD.ru.md](BUILD.ru.md).

## Данные и резервные копии

Нативное приложение хранит всё в файле:

```text
~/Library/Application Support/KanbanFlow/kanbanflow.sqlite
```

Структура базы:

| Таблица | Назначение |
| --- | --- |
| `app_state` | Авторитетный JSON-снимок, который загружает интерфейс |
| `boards`, `columns`, `cards`, `separators` | Нормализованное отражение тех же данных |
| `settings` | Имя приложения, колонки завершения и другие настройки «ключ — значение» |
| `backups` | Последние 20 снимков, созданных при экспорте/импорте |

**Настройки → Reveal Database** открывает расположение базы в Finder. Там же
показаны количество записей и размер файла.

### Полный бэкап и одна доска

- **Export Full Backup (JSON)** сохраняет все доски, карточки, разделители, тему,
  порядок, колонки завершения и имя приложения.
- **Import Backup (JSON)** заменяет содержимое базы данными из файла. Перед
  заменой текущее состояние сохраняется в таблицу `backups`.
- **Export Current Board** сохраняет одну доску.
- **Import Board** добавляет доску из файла и переключается на неё.

В macOS `Cmd+Shift+E` открывает диалог экспорта полного бэкапа, а `Cmd+Shift+I` —
диалог импорта.

## Горячие клавиши

В справке внутри приложения указан `Ctrl`; в macOS те же комбинации работают
с `Cmd`.

| Комбинация | Действие |
| --- | --- |
| `Cmd/Ctrl + Z` | Отменить последнее действие |
| `Cmd/Ctrl + N` | Новая карточка |
| `Cmd/Ctrl + B` | Новая доска |
| `Cmd/Ctrl + E` | Экспорт текущей доски |
| `Cmd/Ctrl + T` | Сменить тему |
| `Cmd/Ctrl + K` | Справка по горячим клавишам |
| `Cmd/Ctrl + ,` | Настройки |
| `/` | Фокус в поиске |
| `Esc` | Закрыть модальное окно или меню досок |
| `1`–`9` | Перейти к колонке |
| `Cmd+Shift+E` | Экспорт полного бэкапа (меню macOS) |
| `Cmd+Shift+I` | Импорт бэкапа (меню macOS) |

## Разработка

Интерфейс — обычные HTML/CSS/JavaScript в `kanban.html`; отдельной сборки
фронтенда нет. После правок пересоберите приложение, чтобы обновлённый HTML
попал в bundle:

```bash
./macos/build.sh
open dist/KanbanFlow.app
```

Чтобы запустить приложение с временной базой и не трогать реальные данные:

```bash
KANBANFLOW_DB_PATH=/tmp/kanbanflow-dev.sqlite \
  ./dist/KanbanFlow.app/Contents/MacOS/KanbanFlow
```

У нативного бинарника есть самотест базы:

```bash
./dist/KanbanFlow.app/Contents/MacOS/KanbanFlow --selftest
```

## Иконка приложения

Исходник иконки — `assets/icon.png`, это должен быть квадратный PNG. После
замены картинки пересоздайте `.icns`:

```bash
./macos/make-icon.sh assets/icon.png
./macos/build.sh
```

## Устранение неполадок

| Проблема | Решение |
| --- | --- |
| `swiftc: command not found` | Выполните `xcode-select --install` и повторите сборку |
| macOS не открывает приложение | Правый клик по приложению → **Открыть** либо разрешите запуск в **Системные настройки → Конфиденциальность и безопасность** |
| Отображается старая иконка | Переместите приложение или выполните `touch dist/KanbanFlow.app`: Finder кеширует иконки |
| Изменения в `kanban.html` не видны | Пересоберите через `./macos/build.sh` — HTML копируется внутрь bundle |
| Нужна чистая база | Закройте приложение и уберите `~/Library/Application Support/KanbanFlow/kanbanflow.sqlite` в сторону |
